## 📂 Project Structure
The project follows a clean **MVVM (Model-View-ViewModel)** architecture:

```text
lib/
├── core/
│   ├── constants/    # Global app constants
│   ├── errors/       # Failure and error handling
│   ├── network/      # API client and network configuration
│   ├── routing/      # GoRouter configuration
│   ├── theme/        # AppTheme and Color schemes
│   └── utils/        # Shared utilities and launchers
├── models/           # Data models (Profile, Project, Job)
├── repositories/     # Data sources and repositories
├── services/         # API, Storage, and Notification services
├── viewmodels/       # Riverpod providers and business logic
├── views/
│   ├── screens/      # Feature screens (Home, Project Detail)
│   └── widgets/      # Reusable UI components
└── main.dart         # App entry point and ProviderScope
```

## 🏃 Getting Started

### Prerequisites
- Flutter SDK (Latest Stable)

### Run Commands
```bash

git clone https://github.com/nitinpanchal123/nitinportfolio.git

# Navigate to project
cd flutter_app

# Install dependencies
flutter pub get

# Run the app
flutter run
```
